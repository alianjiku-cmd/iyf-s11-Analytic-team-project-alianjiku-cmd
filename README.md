# ISDP – Community Skills Development Platform

## 📊 Dashboard & Analytics Team Project

The **Community Skills Development Platform (ISDP)** is a platform designed to connect people with skills, learning opportunities, mentorship, volunteering, and community support.

This project is a team-based web application developed using modern frontend and backend technologies.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/alianjiku-cmd/iyf-s11-Analytic-team-project-alianjiku-cmd.git
```

### 2. Open the project

```bash
cd iyf-s11-Analytic-team-project-alianjiku-cmd
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL provided by Vite, usually:

```text
http://localhost:5173/
```
